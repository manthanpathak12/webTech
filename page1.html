Formatting Styles and Headings

Text Formatting Tags

Bold Tag (<b>): Used to make text bold. No special attributes; just wrap text between <b>...</b>.

Italics Tag (<i>): Used to make text italic. Written as <i>...</i>.

Underline Tag (<u>): Used to underline text. Written as <u>...</u>.

Strike Tag (<strike>): Used to draw a line through text, shown as strikethrough. In modern HTML the <s> tag is preferred.

Subscript Tag (<sub>): Used to write text below the normal line, like H2O.

Superscript Tag (<sup>): Used to write text above the normal line, like X2.

Heading Tags (h1 to h6)

HTML provides six levels of headings, from largest to smallest. No special attributes are needed; just place text between the opening and closing tag.
