Font Styles

Font appearance can be changed using CSS properties like font-family, font-size, and color, applied inline with the style attribute.

Image Tag

tag is used to insert images. It is a self-closing tag with important attributes:

  • src - path or URL of the image (required)
  • alt - alternate text shown if image fails to load
  • width / height - dimensions of the image
  • title - tooltip text shown on hover
