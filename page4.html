Other Tags: br, hr, pre, p

br - Line Break

The br tag inserts a single line break. It is an empty (self-closing) tag with no attributes.

Roses are red,
Violets are blue,
The br tag breaks lines,
Without starting anew.

hr - Horizontal Rule

The hr tag draws a horizontal line, often used to separate sections of content.

Above this line is one section.

Below the line is another section.

pre - Preformatted Text

The pre tag displays text exactly as written in the HTML file, preserving spaces and line breaks. It is commonly used to show code.

function greet() {
    console.log("Hello, World!");
}

p - Paragraph

The p tag defines a paragraph of text. Browsers automatically add space before and after each paragraph.

This is a first paragraph written using the p tag.

This is a second, separate paragraph, also using the p tag.
